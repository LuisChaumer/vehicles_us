# vehicles_us

Esta aplicación web, desarrollada con Streamlit, permite la visualización interactiva de datos de vehículos en venta. Los usuarios pueden generar gráficos para analizar la relación entre el kilometraje y el precio, así como explorar la distribución del kilometraje de los vehículos.

Funcionalidades

Histograma del kilometraje: Muestra la distribución de los valores de odómetro en el conjunto de datos.

Gráfico de dispersión: Representa la relación entre el kilometraje (odometer) y el precio (price).

Interfaz interactiva: Permite a los usuarios generar gráficos mediante botones o casillas de verificación.
